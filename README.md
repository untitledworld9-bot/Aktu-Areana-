# AKTU Arena — AKTU B.Tech 1st Year Exam Mastery & 1v1 Battleground

AI-powered competitive learning platform engineered specifically for **Dr. A.P.J. Abdul Kalam Technical University (AKTU, Lucknow)** B.Tech 1st Year engineering students (Academic Session 2026–27).

---

## 🌟 Key Features

- **Full Curriculum Syllabus Question Vault**: Covers all 8 core subjects (Engineering Mathematics I & II, Engineering Physics, Engineering Chemistry, C Programming / PPS, AI & Prompt Engineering, Basic Electrical Engineering, Digital Electronics, and Mechanical Engineering).
- **Gamified Subject Mastery Roadmap**: Real-time XP, 5 distinct mastery tiers (Novice, Apprentice, Specialist, Master, and Grandmaster), custom subject badges, and progress tracking.
- **1v1 Real-time Battle Duels**: Challenge peer engineers across 750+ AKTU colleges with synchronized live timers and leaderboard MMR.
- **Engineering Community Feed**: Discussion boards, unit notes exchange, solved semester PYQs, and topic filtering.
- **State Leaderboard**: College and state-level rank badges (Vanguard, Grandmaster, Apex Scholar).
- **PWA (Progressive Web App)**: Installable directly on Android, Windows, and iOS with offline caching, high-resolution icons, and native standalone feel.
- **Adaptive Dark & Light Mode**: Complete, high-contrast, beautiful themes for study day or night.
- **Cloudflare Worker & Gemini AI**: Serverless AI generation powered by Google AI Studio Gemini API with resilient curriculum fallbacks.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
